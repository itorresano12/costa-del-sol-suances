# AGENTS.md - Apartamento Costa del Sol Suances

## REGLA DE ORO
Cada vez que termines de implementar o modificar una funcionalidad y verifiques que no hay errores de compilación, debes ejecutar automáticamente `git add .`, `git commit -m 'feat: descripción clara del cambio'` y `git push origin main` sin que el usuario tenga que pedirlo.

## Proyecto
Web oficial de reserva directa para "Apartamento Costa del Sol Suances" (Suances, Cantabria).
Construida con Astro + Tailwind CSS + TypeScript.
Sincronización bidireccional con Booking y Airbnb vía iCal.
Stripe Checkout y reserva bancaria manual / Bizum.
